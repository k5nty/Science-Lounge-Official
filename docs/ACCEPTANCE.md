# Приёмка по ТЗ

Критерии из раздела 10 ТЗ и где их проверять.

| Критерий | Как проверить | Результат |
| --- | --- | --- |
| Все страницы раздела 5 первого этапа работают на телефоне и десктопе | пройти: главная, расписание, выпуск (анонс и материал), лекторы, лектор, О нас, отзыв, 404 | Проверено в браузере 390 px и 1360 px |
| Прошедшие лекции свёрнуты в расписании и уходят туда сами | `/raspisanie`: блок «Показать прошедшие (N)»; «прошедшая» = через 3 часа после начала | Автотест `scheduled publication…`; правило в `lib/dates.js::isPast` |
| Пустые необязательные блоки выпуска не показываются | выпуск без видео, слайдов, фото, автографа | Условия в `views/pages/issue.njk` |
| Отзыв по QR уходит меньше чем за 30 секунд; уведомление в Telegram | `/otzyv/<slug>`: оценка → «Отправить» (одна форма, три необязательных поля); бот присылает сообщение | Нужен токен бота на проде (`docs/DEPLOY.md`) |
| Ученик без опыта публикует выпуск по инструкции за 20 минут | дать `docs/KAK-VESTI-SAYT.md` ученику, засечь время | Выполняется людьми после выкладки |
| Lighthouse на телефоне ≥ 90 / 95 / 95 | `npx lighthouse https://сайт/ --only-categories=performance,accessibility,seo` | Локально: Performance 92–95, Accessibility 96–100, SEO 100 |
| Ни одного пункта из списка «нельзя» (7.5) | сверить дизайн со списком (ниже) | См. ниже |
| Политика ПД, согласия, cookie-баннер на месте; данные на российском сервере | `/politika`; формы с чекбоксом; баннер при `METRIKA_ID` | Политика — черновик для юриста; сервер выбирает заказчик |
| Доступы к хостингу, домену, CMS и репозиторию переданы заказчику | организационно | Выполняется при сдаче |

## Список «нельзя» (7.5)

| Пункт | Состояние |
| --- | --- |
| фиолетово-синие градиенты, неон, стекло, размытые пятна | нет; цвета: бумага, чернила, один синий акцент |
| картинки от нейросетей, 3D, стоковые фото | нет; обложки только реальные кадры, до загрузки — типографика и точечные портреты-заглушки |
| три карточки «преимуществ» с иконками, эмодзи | нет |
| слоган «Наука, которая вдохновляет» и «Узнать больше» | нет; первый экран — ближайшая лекция |
| тексты «погрузитесь в мир науки», «уникальная возможность» | нет; рекламных штампов в шаблонах нет |
| скругления 16–24 px, мягкие тени | скругления 2 px, теней нет |
| всё по центру и симметрично | асимметричная сетка 7+3 из 12 колонок |
| счётчики, которые накручиваются | нет, цифры статичны |
