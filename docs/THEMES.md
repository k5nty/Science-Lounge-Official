# Пять оформлений сайта

Содержимое одно, оформлений пять. Переключатель «Оформление» стоит внизу слева на каждой странице; выбор запоминается в браузере. Ссылкой: `/?theme=events`.

| id | Название | Образец | Что другое |
| --- | --- | --- | --- |
| `journal` | Журнал | Arzamas, Tufte CSS | Строгий научный журнал по ТЗ: бумага, чернила, синий акцент, пронумерованные выпуски, поля для цитат |
| `campus` | Университет | Gresham College | Серьёзная шапка с панелью, главный материал и колонка ближайших лекций, превью 16:9, кнопки «Смотреть / Читать» |
| `plain` | Текст | Long Now | Логотип по центру, меню по краям, списки «дата — портрет — имя» с тонкими линиями, почти без кнопок |
| `events` | Афиша | Royal Institution, What's on | Жёлтая полоса с заголовком, карточки с фото и тегом, жирные заголовки, круглая жёлтая кнопка «Регистрация» |
| `press` | Издание | Quanta Magazine | Тёмная шапка с иконками, главный материал с крупным заголовком, колонки статей и боковая панель, оранжевый акцент |

**Какое оформление видят посетители.** Админка → Настройки → «Дизайн сайта» → «Оформление по умолчанию». Там же переключатель «Показывать переключатель оформлений»: пока вы сравниваете, он включён; перед запуском выключите, тогда параметр `?theme=` перестаёт работать.

**Важно.** Все пять сделаны по реальным сайтам-образцам из ТЗ (раздел 7.1) и без «ИИ-приёмов»: градиентов, стекла, свечения. Только `journal` следует остальным требованиям раздела 7 ТЗ (шрифты, цвета, сетка 7+3). Остальные четыре сделаны по отдельной просьбе владельца как варианты для сравнения. Содержимое, SEO, формы, согласия на фото, админка работают одинаково во всех.

## Как устроена тема

См. `docs/THEME-CONTRACT.md`: файлы темы, правила, переменные шаблонов и разметка. Кратко:

- `public/css/themes/<id>.css` — обязателен, грузится после `site.css`;
- `public/js/themes/<id>.js` — анимации (по желанию);
- `src/views/themes/<id>/{header,footer,home,schedule,archive,lecturers}.njk` — замена частей разметки (по желанию);
- новая тема: добавьте запись в `src/themes.js` и файлы выше.
