## Как получить одобрение лектора

1. Отправьте лектору его текст и письмо по шаблону из файла [pismo-lektoru.md](pismo-lektoru.md).
2. Внесите правки лектора в файл `.md` его лекции.
3. Обновите страницу лекции на сайте: перенесите туда исправленный текст, замените метку «не проверено лектором» на «проверено лектором» и смените пометку над текстом на «Текст согласован с лектором».

Шаг 3 удобно поручить Claude: достаточно прислать правки лектора и попросить обновить страницу.
